# Отряд 320

Сайт-квест на день рождения Шуры. Ему дарят шлем (надпись BORN TO KILL, сбоку номер 320 410-68) и текилу для текила бума. Сайт рассказывает про секретный Текила-бум отряд 320, Шура находит спрятанный шлем, вводит номер с него, открывает досье отряда, принимает присягу, и вы вместе делаете текила бум.

Сайт: https://71ggffh-netizen.github.io/otryad-320/

Ссылку не скидывайте в общие чаты, пока Шура не прошёл квест. Репозиторий публичный, сайт закрыт только от поисковиков.

## Что где лежит

| Файл | Что это |
|------|---------|
| `index.html` | Весь сайт: вёрстка, стили, скрипт и звуки (звуки синтезируются в браузере, файлов нет) |
| `media/I1…I5` | Картинки. На `I3_table.jpg` номер со шлема специально закрашен, чтобы его нельзя было ввести, не найдя шлем |
| `media/V1…V5` | Видео, пережатые под мобильный интернет, плюс постеры (первый кадр) |
| `media/R1_briefing.mp4` | «Учебный фильм отряда» со звуком: момент, когда Шура узнаёт про текила бум |
| `media/I2_soldier_top.jpg` | Солдат без стопки в кадре (оригинал `I2_soldier.jpg` её показывает) |
| `.nojekyll` | Нужен GitHub Pages, не трогать |

## Что поправить перед вручением

В начале `<script>` в `index.html` есть блок `CONFIG`. Всё, что меняется под Шуру, собрано там:

```js
const CONFIG = {
  name: "Шура",              // как обращаться в тексте
  fullName: "Шура",          // имя и фамилия для удостоверения
  callsign: "Фотокор",       // позывной
  hint: "...",               // подсказка, где спрятан шлем (экран «Последнее донесение»)
  night: "В ночь перед твоим днём рождения",   // когда исчез рядовой Н.
  extraAchievements: [ ... ] // свои пункты в «Основания для зачисления»
};
```

Там же `age` (возраст, главное условие вербовки), `hintPhoto` (фото-наводка на шлем, пока пусто — на экране заглушка «Засекречено»), `squad` (карточки бойцов на экране «Знакомство с отрядом»: позывной, имя, подпись) и `spy` (улики в досье наблюдения за Шурой).

Порядок: радиосвязь → предыстория (вербовка, отбор, 4 предупреждения, шлем, задание №1) → ввод номера → досье лист 1 (номер, девиз) → знакомство с отрядом → досье наблюдения → личное дело → **учебный фильм (раскрытие)** → посвящение → бум → удостоверение.

**Главное правило сюжета:** до учебного фильма нигде нет ни слова про текилу, бум, стопки, шоты, бутылки и закуску. Шеврон в досье размыт, потому что на нём нарисована стопка с лаймом. Расшифровка девиза в досье заканчивается штампом «Засекречено», а «Шоты.» звучит только после фильма. Добавляете текст до фильма? Проверьте его по этому списку.

Текст предыстории лежит в массиве `DOCS`, остальное прямо в HTML. Фото отряда `media/S*`, досье наблюдения `media/D*`.

## Как выложить правки

Пушите в `main`, GitHub Pages пересоберёт сайт примерно за минуту. Браузеры могут держать старую версию до 10 минут, поэтому последние правки заливайте минимум за полчаса до вручения. Ссылка не меняется, так что QR пересоздавать не нужно.

Смотреть локально:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Лучше смотреть через сервер, а не двойным кликом по `index.html`: при открытии из файла браузер может не дать сохранить удостоверение картинкой.

## Тестирование

Прогресс сохраняется в браузере, и после обновления страницы квест продолжается с того же места. Чтобы начать заново, откройте сайт с `?reset` в конце:

https://71ggffh-netizen.github.io/otryad-320/?reset

Шура будет проходить квест со своего телефона, ваши тесты на него не влияют.

## Если поменяется номер на шлеме

Номер не лежит в коде открытым текстом. В скрипте хранится его хеш `CODE_H`, а `PREFIX_H` хранит хеш первых трёх цифр для подсказки «отряд опознан». Новые значения посчитать так:

```bash
python3 -c "
def h(s):
  x=7
  for c in s: x=(x*31+ord(c))%2**32
  return x
print(h('32041068'), h('320'))"
```

Номер в видео V5 при этом останется старым. `I5_shura.jpg` и `V4_nod.mp4` больше не используются: в личном деле и удостоверении теперь `ID_shura.jpg`.

В самом конце, на экране удостоверения, есть кнопка «Дополнительный подарок» (экран `#gift`): месяц Claude от подразделения, за ним надо обратиться к агентам Михаилу и Сергею.
